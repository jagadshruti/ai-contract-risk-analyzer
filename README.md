# AI Contract Risk Analyzer

This project shows how AI can help lawyers identify risky clauses in contracts.

## What it does
- Finds risky clauses
- Labels risk as High / Medium / Low
- Explains the risk in simple language

## Why this matters
Lawyers spend hours reviewing contracts. This tool helps save time and reduce errors.

## Example

Clause:
Vendor shall not be liable for any indirect damages.

AI Output:
- Risk: High  
- Reason: Vendor avoids responsibility  
- Suggestion: Add limits instead of full exclusion
